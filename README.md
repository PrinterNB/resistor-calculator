# Resistor Calculator

A simple resistor color band calculator for common 4-band and 5-band resistors. Pick the resistor type, choose the color of each band, and the resistance updates instantly.

The camera scanner can sample a resistor's bands on-device. Open the camera over HTTPS or localhost, place the resistor horizontally along the guide, and press **Scan resistor**. The detected bands are shown for review before they are applied to the calculator. Bright, even lighting works best; the manual controls are available for correcting a difficult scan.

The first band is marked in the preview so it is easier to tell which ring to read from first.

## Live Version

The live version can be found at [resistor.parkerbrown.photos](https://resistor.parkerbrown.photos).

## Run Locally

Open [index.html](index.html) in a browser for the manual calculator. Camera access requires HTTPS or localhost, so use a local web server when testing the scanner.
